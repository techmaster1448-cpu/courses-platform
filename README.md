# منصة دورات مهارات المستقبل 🎓

منصة تدريبية حديثة لعرض وإدارة دورات تدريبية متنوعة من مركز "مهارات المستقبل".

## المميزات ✨

- ✅ عرض شامل للدورات مع معلومات تفصيلية
- ✅ تصنيف وتجميع الدورات حسب المجال
- ✅ بحث وتصفية متقدمة
- ✅ نظام تسجيل الطلاب
- ✅ لوحة الطالب الشخصية
- ✅ لوحة التحكم الإدارية
- ✅ إدارة الدورات والفئات
- ✅ نظام المصادقة الآمن

## المتطلبات الأساسية 📋

### Backend
- Node.js (v14 أو أحدث)
- MongoDB
- npm أو yarn

### Frontend
- Node.js
- npm أو yarn
- المتصفح الحديث

## التثبيت والإعداد 🚀

### 1. استنساخ المشروع
```bash
cd COURSES
```

### 2. إعداد Backend
```bash
cd backend
npm install

# إنشاء ملف .env بالإعدادات الخاصة بك
# يمكنك نسخ .env الموجود والتعديل عليه

# بدء الخادم
npm run dev  # في وضع التطوير
npm start    # في الإنتاج
```

سيبدأ الخادم على `http://localhost:5000`

### 3. إعداد Frontend
```bash
cd frontend
npm install

# التأكد من أن ملف .env يحتوي على الإعدادات الصحيحة
# REACT_APP_API_URL=http://localhost:5000/api

# بدء تطبيق React
npm start
```

سيفتح التطبيق على `http://localhost:3000`

## API Endpoints 🔌

### المصادقة
- `POST /api/auth/register` - تسجيل طالب جديد
- `POST /api/auth/login` - تسجيل الدخول
- `GET /api/auth/me` - الحصول على بيانات المستخدم الحالي

### الدورات
- `GET /api/courses` - الحصول على جميع الدورات
- `GET /api/courses/:id` - الحصول على دورة محددة
- `POST /api/courses` - إضافة دورة جديدة (مسؤول فقط)
- `PUT /api/courses/:id` - تعديل دورة (مسؤول فقط)
- `DELETE /api/courses/:id` - حذف دورة (مسؤول فقط)

### الفئات
- `GET /api/categories` - الحصول على جميع الفئات
- `POST /api/categories` - إضافة فئة جديدة (مسؤول فقط)

### الحجوزات
- `GET /api/enrollments/student/:studentId` - دورات الطالب
- `POST /api/enrollments` - الاشتراك في دورة
- `DELETE /api/enrollments/:enrollmentId` - إلغاء الاشتراك

## الصفحات الرئيسية 📄

- **الرئيسية** `/` - عرض الدورات المميزة والمعلومات العامة
- **الدورات** `/courses` - قائمة جميع الدورات مع البحث والتصفية
- **تفاصيل الدورة** `/courses/:id` - معلومات كاملة عن الدورة
- **التسجيل** `/register` - نموذج إنشاء حساب جديد
- **الدخول** `/login` - صفحة تسجيل الدخول
- **لوحة الطالب** `/student-dashboard` - الدورات المسجلة والتقدم
- **لوحة التحكم** `/admin-dashboard` - إدارة الدورات والفئات

## حل المشاكل الشائعة 🔧

### مشكلة: "Cannot connect to MongoDB"
**الحل:** 
- تأكد من تشغيل MongoDB
- تحقق من قيمة `MONGODB_URI` في ملف `.env`

### مشكلة: "CORS Error"
**الحل:**
- تأكد من أن `CORS_ORIGIN` في Backend يطابق عنوان Frontend
- تحقق من أن Frontend و Backend يعملان على نفس الشبكة

### مشكلة: "Port already in use"
**الحل:**
```bash
# تغيير المنفذ في .env
PORT=5001
```
